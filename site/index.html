怎么发帖
  1. 在下面写好你的经历，先看脱敏预览 —— 敏感信息会被替换成「某校」「某老师」
  2. 点「绑定 GitHub 账号」完成授权（点两下就好），之后就能一键发布； 不想绑定也可以点「复制脱敏结果」，再到 GitHub 新建讨论主题（分类选 experiences）把内容粘进去
  3. 标题写成 你的处境 [压榨]，标签可选：压榨 / PUA / 谩骂 / 人格污蔑 / Push / 其他
  4. 正文第一行加一句 > 策略: reduce，说明你想怎么应对： avoid 忍一忍 · reduce 硬刚回去 · transfer 找人帮忙 · escape 溜之大吉
  5. 想看别人的回应，去该主题的评论区留言即可

第 2 步 · 等待授权中…（可以关掉这个页面，完成后会自动跳回来）
粘贴 GitHub 访问令牌
令牌只保存在当前页面的内存里，刷新即失效，不会写入浏览器存储。
生成方式：GitHub → 右上角头像 → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token， 然后只勾选：
  1. Repository access 选 Only select repositories，只选 PGrefuge 论坛仓库
  2. Repository permissions → Discussions 选 Read and write
  3. 其余权限一项都不要勾
这样这个令牌只能给论坛发讨论，读不了你的其他仓库。
