怎么发帖
  1. 点下面的「写经历」，在 GitHub 上新建一个讨论主题（分类选「经历」）
  2. 标题写成 你的处境 [压榨]，标签可选：压榨 / PUA / 谩骂 / 人格污蔑 / Push / 其他
  3. 正文写下你的经历。不用自己打码 —— 学校、学院、导师姓名会由服务端自动替换成「某校」「某老师」
  4. 正文第一行加一句 > 策略: reduce，说明你想怎么应对： avoid 忍一忍 · reduce 硬刚回去 · transfer 找人帮忙 · escape 溜之大吉
  5. 想看别人的回应，去该主题的评论区留言即可
